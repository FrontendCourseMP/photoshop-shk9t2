# GrayBit Studio

Одностраничный учебный редактор изображений для лабораторной работы №1.

**Демо:** https://frontendcoursemp.github.io/photoshop-shk9t2/

## Возможности

- Загрузка PNG, JPG/JPEG и учебного формата GB7.
- Отрисовка исходного изображения на HTML5 Canvas.
- Скачивание текущего изображения в PNG, JPG и GB7.
- Самостоятельно реализованные кодер и декодер GrayBit-7; при экспорте в GB7 изображение корректно переводится в 7-битные оттенки серого, прозрачность сохраняется бинарной маской.
- Строка состояния с форматом, исходным именем, шириной, высотой и глубиной цвета.
- Адаптивный интерфейс: небольшие изображения занимают естественный размер, большие уменьшаются в пределах viewport без потери исходного разрешения.

## Запуск

```bash
npm install
npm run dev
```

Проверить кодек: `npm test`. Сборка для публикации: `npm run build`.

## GB7

Файл начинается с 12-байтного заголовка `GB7 0x1D`, затем следуют пиксели сверху вниз. В каждом пикселе младшие 7 бит — яркость (0–127), старший бит — маска прозрачности, если установлен флаг маски. Ширина и высота записаны как unsigned 16-bit big-endian.

## Публикация

При push в `main` GitHub Actions собирает Vite-приложение и публикует `dist` в GitHub Pages. В настройках репозитория должен быть выбран источник **GitHub Actions**.
