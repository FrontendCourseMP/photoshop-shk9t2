# GrayBit Studio

Одностраничный учебный редактор изображений для лабораторной работы №3.

**Демо:** https://frontendcoursemp.github.io/photoshop-shk9t2/

## Возможности

- Загрузка PNG, JPG/JPEG и учебного формата GB7.
- Отрисовка исходного изображения на HTML5 Canvas.
- Скачивание текущего изображения в PNG, JPG и GB7.
- Самостоятельно реализованные кодер и декодер GrayBit-7; при экспорте в GB7 изображение корректно переводится в 7-битные оттенки серого, прозрачность сохраняется бинарной маской.
- Строка состояния с форматом, исходным именем, шириной, высотой и глубиной цвета.
- Адаптивный интерфейс: небольшие изображения занимают естественный размер, большие уменьшаются в пределах viewport без потери исходного разрешения.
- Панель каналов с миниатюрами: RGB/RGBA или «Яркость»/Alpha для GB7; любое число каналов можно включать и выключать без изменения исходника.
- Инструмент «Пипетка»: координаты пикселя, RGBA и координаты CIELAB.
- Масштаб отображения на главном экране: диапазон и пресеты 12%–300%, авто-fit при загрузке с отступами 50 пикселей, clamp в диапазон.
- Инструмент «Изменить размер» в модальном окне: собственные реализации билинейной интерполяции (по умолчанию) и ближайшего соседа, расширяемый интерфейс методов; расчёт мегапикселей до/после, единицы %/px, связь пропорций, валидация полей, tooltip с описанием алгоритмов.
- Обобщённый переиспользуемый компонент модального окна на нативном `<dialog>`.
- Инструмент «Уровни» (Levels): раздельная коррекция Master/R/G/B/Alpha, точки чёрного/белого, гамма 0.1–9.9, гистограмма с линейным/логарифмическим масштабом, LUT-оптимизация, предпросмотр в реальном времени.
- Инструмент «Фильтрация / Ядро 3×3»: 6 преднастроенных ядер (тождественное, повышение резкости, Гаусс 3×3, Box-blur, Прюитт X/Y), редактируемая сетка 3×3, 3 стратегии заполнения края (чёрный, белый, копирование), выбор каналов R/G/B/A для применения, асинхронная свёртка с прогрессом и отменой предпросмотра.

## Запуск

```bash
npm install
npm run dev
```

Проверить кодек: `npm test`. Сборка для публикации: `npm run build`.

## GB7

Файл начинается с 12-байтного заголовка `GB7 0x1D`, затем следуют пиксели сверху вниз. В каждом пикселе младшие 7 бит — яркость (0–127), старший бит — маска прозрачности, если установлен флаг маски. Ширина и высота записаны как unsigned 16-bit big-endian.

## Публикация

При push в `main` GitHub Actions собирает Vite-приложение и публикует `dist` в GitHub Pages. В настройках репозитория должен быть выбран источник **GitHub Actions**.
